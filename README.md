«Диамагнетик» продает инструменты, товары для дома и технические изделия через сеть магазинов.
Необходимо разработать систему учета иерархического каталога, характеристик товаров, поставщиков,
закупок, комплектов, распределения между магазинами, цен, продаж, возвратов и гарантийного
обслуживания.
Категории товаров образуют иерархию. Для категории задается набор допустимых характеристик, а
конкретный товар хранит значения соответствующих характеристик. Некоторые товары учитываются
поштучно по серийному номеру, другие — только количественно. Способ учета задается для товара и не
должен меняться после появления складских операций без процедуры миграции.
С поставщиками заключаются договоры, внутри которых ведется история закупочных цен. Магазины
формируют заявки на пополнение; одна заявка может быть частично удовлетворена несколькими
поставками. Поставка может объединять позиции из нескольких заявок, поэтому необходимо хранить
распределение фактически поставленного количества по заявкам.
Часть товаров продается комплектами. Комплект имеет версионируемый состав: количество
компонентов и допустимые замены. При продаже комплекта остатки уменьшаются по его фактическому
составу. Один и тот же компонент может входить в разные комплекты. Система должна исключать
проведение комплекта при недостатке хотя бы одного обязательного компонента.
Розничные цены зависят от региона и периода. Продажа серийного товара должна фиксировать
конкретный экземпляр. Возврат ссылается на исходную продажу; для серийной позиции должен
возвращаться тот же экземпляр либо оформляться отдельный акт несоответствия.
Гарантийное обращение содержит проданный экземпляр, описание неисправности, решение и историю
ремонта. Руководитель получает отчеты по поставщикам, частичным поставкам, дефициту компонентов
комплектов, возвратам, гарантийным дефектам и маржинальности товарных категорий.
